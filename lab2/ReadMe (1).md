## Теоретическая часть

### Расстояние Левенштейна

**Расстояние Левенштейна** между двумя строками — это минимальное количество операций вставки, удаления и замены одного символа, необходимых для преобразования одной строки в другую.

Например:
- `кот` → `кит`: 1 замена (`о`→`и`) - 2
- `стол` → `стул`: 1 замена (`о`→`у`) - 2
- `пирог` → `пир`: 2 удаления - 2

### Принцип оптимальности Беллмана

Принцип утверждает:  
> *An optimal policy has the property that whatever the initial state and initial decisions are, the remaining decisions must constitute an optimal policy with regard to the state resulting from the first decision*

В контексте расстояния Левенштейна это означает, что оптимальный путь преобразования строки `A[1..i]` в `B[1..j]` зависит от оптимальных путей преобразования более коротких подстрок:
- `A[1..i-1] → B[1..j]` (удаление)
- `A[1..i] → B[1..j-1]` (вставка)
- `A[1..i-1] → B[1..j-1]` (замена или совпадение)

Это позволяет использовать **динамическое программирование** для эффективного вычисления расстояния.

### Рекуррентная формула

Пусть `dp[i][j]` — расстояние между префиксами `word1[0..i-1]` и `word2[0..j-1]`.

Тогда:
```
dp[0][j] = j
dp[i][0] = i
dp[i][j] = min(
dp[i-1][j] + 1, // удаление
dp[i][j-1] + 1, // вставка
dp[i-1][j-1] + cost // замена (cost = 0, если символы равны, иначе 2)
)
```

## Задача №6: организация утренника

> *Цель: сформировать минимальное количество групп детей так, чтобы разница в возрасте внутри каждой группы не превышала 2 года.*

Вам нужно организовать детский утренник, на который пришло `nkids` детей. У каждого ребёнка есть номер `id` и возраст `age`.

Вы хотите получить минимальное количество групп, но при этом возраст детей в каждой группе не должен отличаться больше, чем на 2 года.

### Функция (C++)

```cpp
#include <vector>

struct kid_t {
    int id;
    int age;
};

struct kidgroup_t {
    int nkid;     // количество детей в группе
    int ngroup;   // номер группы (начиная с 0 или 1 — по вашему выбору)
};

struct answer_t {
    int ngroups;          // общее количество групп
    kidgroup_t* mapping;  // массив размером nkids, где mapping[i] — группа для kids[i]
};

answer_t funparty(kid_t* kids, int nkids);
```

---

### Пример:

Дети:  
- `(id=1, age=5)`  
- `(id=2, age=7)`  
- `(id=3, age=6)`  
- `(id=4, age=10)`  
- `(id=5, age=8)`

После сортировки по возрасту:  
- `(1,5)`, `(3,6)`, `(2,7)`, `(5,8)`, `(4,10)`

Группы:
- Группа 0: дети с возрастами 5,6,7 → разница 2 → допустимо.
- Группа 1: дети с возрастами 8,10 → разница 2 → допустимо.

Результат: `ngroups = 2`, `mapping = [0,1,0,1,0]` (если нумерация групп с 0).
